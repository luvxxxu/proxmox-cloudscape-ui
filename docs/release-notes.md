공개 릴리스로 설치하고 자동 업데이트할 수 있습니다. 사용자 GitHub 계정이나 PAT가 필요하지 않습니다.

- Debian 12/13 amd64 LXC용 사전 빌드 앱과 Node 24 실행 파일 제공
- Caddy 외부 HTTPS 구성 지원, 내부 IP 및 Proxmox 연결 검사
- 릴리스 파일의 크기와 SHA-256 검증, 안전한 압축 해제
- 새 안정 버전 자동 확인, 서비스 상태 검사와 실패 시 이전 앱·Node 복구
